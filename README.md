# 四字熟語クイズアプリ

じいちゃんとクイズ大会をしよう!

四字熟語の 1 文字が穴になっていて、4 つの選択肢から正しい漢字をタップして答える。
10 問で 1 セクションが終わり、何問正解できたかを表示する。

## 使う人と、そこから決まったこと

祖父がタブレットで遊ぶことだけを考えて作ってある。以下は好みではなく、要件から来ている。

- **デジタルに不慣れ** … 画面に出る操作は常に 1 種類だけ。設定もメニューも戻るボタンも無い。
  ルーターを持たないので、ブラウザの戻るで状態が壊れることもない。
- **耳がほとんど聞こえない** … 音は一切使わない。正誤は ◯✕ のアニメーションだけで伝える。
  タップの手応えも、ボタンが沈む見た目で返している。
- **Android タブレットを横向きで使う** … 横向き固定、スクロールなし、1 画面に収める。
  戻る操作でアプリが終了しないよう、履歴にダミーを積んで無効化している。
  考えている間に画面が消えないよう、Wake Lock で点灯を維持する。
- **漢字に強い（漢検 2 級相当）** … 「熟語を知らないと解けない問題」は作らない。
  構成漢字の意味から辿り着ける難問にしてある。難易度の配分は 普通 4 問・難しめ 4 問・とても難しい 2 問。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # データ検証とロジックのテスト
npm run lint
npm run build    # dist/ に本番ビルド（Service Worker もここで生成される）
npm run preview  # ビルド結果の確認
```

## 問題を増やす

`src/data/idioms.json` に追記するだけでよく、コードは触らない。

```json
{
  "id": "gashin-shoutan",
  "idiom": "臥薪嘗胆",
  "reading": "がしんしょうたん",
  "blankIndex": 1,
  "choices": ["薪", "新", "身", "辛"],
  "meaning": "薪の上に臥し、苦い胆を嘗める。目的のため苦労に耐えること。",
  "level": "hard"
}
```

- `blankIndex` は穴にする文字の位置（0 始まり）。正解は `idiom` と `blankIndex` から導出するので、
  正解を別のフィールドに持たせない。データの食い違いが起きないようにするため。
- `choices` には正解を 1 つ含めて 4 つ。並び順は表示時にシャッフルされる。
- `meaning` は間違えたときだけ表示される。
- `level` は `normal` / `hard` / `veryHard`。各難易度の在庫が配分（4 / 4 / 2）を下回ると、
  テストが落ちて教えてくれる。

追記したら必ず `npm test` を実行する。選択肢に正解が無い、選択肢が 3 つしかない、
といった手入力のミスは全部ここで落ちる。

### 問題を作るときの勘どころ

難易度は熟語の珍しさではなく、**誤答の選択肢の作り方**で決まる。効くのは 3 つ。

1. 世間でよくある誤字を混ぜる（「危機一髪」に対する「発」）
2. 同音の漢字で 4 つ揃える（「眼光紙背」に対する 紙・誌・志・史）
3. 字形の似た漢字で揃える（「画竜点睛」に対する 睛・晴・精・清）

## デプロイ

Cloudflare Pages にリポジトリを繋ぎ、ビルドコマンド `npm run build`、出力ディレクトリ `dist` を指定する。
GitHub Pages を使う場合はサブパス配信になるため、`vite.config.ts` の `base` と
manifest の `start_url` / `scope` を合わせる必要がある。

タブレットでは Chrome のメニューから「アプリをインストール」を選び、ホーム画面に置く。
以降はアイコンから全画面で起動し、オフラインでも動く。

## アイコンを作り直す

`public/icons/*.svg` が元データ。macOS なら以下で PNG を再生成できる。

```bash
cd public/icons
qlmanage -t -s 512 -o . icon.svg icon-maskable.svg
mv icon.svg.png icon-512.png
mv icon-maskable.svg.png icon-maskable-512.png
sips -z 192 192 icon-512.png --out icon-192.png
```

## 実機で必ず見ること

- 選択肢の漢字が豆腐（□）になっていないか。「睛・狗・捲・扼・沐・陋」は常用漢字の外にある。
- 文字の大きさとボタンの間隔。隣を押してしまわないか。
- 正解のあと、自動で次に進むまでの速さ。急かされていないか（`src/config.ts` で調整する）。
